# Haul
Phone dashboard for towing a heavy trailer on I-90 Missoula, MT → Coeur d'Alene, ID (Lookout Pass), with alternates.
Data refreshed every 20 min by GitHub Actions from public sources: Montana DOT 511 (Iteris public map feeds + MDT RWIS), Idaho 511 public map layers, NWS api.weather.gov, aviationweather.gov METARs, OSRM routing, sunrise-sunset.org.
Town-level points only. Not a substitute for official 511 or posted signs.
